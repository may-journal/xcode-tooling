### 2026.11.05.2100

> Any app gets its App Store screenshots from one tool, whenever the app changes and before each release.

- Feat: `screenshots.sh` captures each frame at each size and deletes every simulator it made.
- Feat: `screenshots-compose.swift` sets each headline from the doc above its screen.
- Feat: `screenshots-agent.sh` installs a launchd agent, and `screenshots-watch.sh` captures each commit that changes the app once.
- Feat: `screenshots-release.sh` and the `capture_for_release` lane capture from the release commit before any upload.
- Feat: a `screenshots` lane runs the capture and uploads nothing, and the sizes run at once.
